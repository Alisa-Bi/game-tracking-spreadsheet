# game-tracking-spreadsheet

## Description

A simple offline Game Tracker that saves your progress, playtime, and ratings using localStorage and JSON backups. The appearance is customizable. It's a single HTML-file with CSS and JS.

* Save all entries in localStorage by clicking on "Save Game".
* Supports auto-save on Chromium based browser by updating a JSON file.
* On non-Chromium based browsers, You can download and upload the JSON file manually.
* **Important:** Save your JSON file before moving the tracker HTML to a different folder or device to avoid losing data.
